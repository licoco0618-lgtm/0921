# 智光商工 115學年度 新生（一年級）繡學號作業系統

本系統依據學校發布之三份正式 PDF 規範檔案（01 日程表、02 流程圖解、03 收費明細表）進行數位化建置，提供導師、班長、總務股長與同學一站式的送繡管理與收費計算工具。

---

## 📁 檔案清單與說明

| 檔案名稱 | 說明 |
| :--- | :--- |
| **`點我啟動.bat`** | **快速捷徑**：直接雙擊即可自動以瀏覽器開啟本系統。 |
| **`index.html`** | **系統主程式**：完整的單頁 Web 應用程式，包含四大功能模組。 |
| **`style.css`** | **視覺與列印樣式表**：包含現代化 UI 設計與專門針對 A4 列印優化之排版樣式。 |
| **`app.js`** | **系統運算邏輯**：31 位學生資料管理、費用即時計算、資料自動儲存與 CSV 匯出匯入。 |
| **`03_智光商工115學年度新生繡學號各班收費明細表_31人.csv`** | **Excel 試算表範本**：預設包含 31 位學生之完整欄位，UTF-8 BOM 編碼，可用 Excel 直接開啟。 |

## 🌟 核心功能特色

### 1. 📋 03 各班收費明細表（31人完整名冊）
- **預設班級**：資處一仁（亦可於介面自訂修改）。
- **完整 31 人編制**：預設建置座號 1 ~ 31 位學生名冊，無須逐一手動增減。
- **📱 行動端雙檢視自由切換 (全新升級)**：
  - **📱 卡片檢視 (手機推薦)**：專為手機螢幕量身訂做，每位學生獨立精緻卡片，配備大面積觸控步進器（單手點擊 `+` / `-` 靈敏防誤觸）、直覺式一鍵繳費開關、單人全套快速設定。
  - **📊 試算表格 (支援左右滑動凍結欄)**：橫向滑動檢視各品項時，「座號」與「姓名」雙欄位強制凍結於螢幕左側，不再迷航。
- **🔍 即時搜尋與催繳篩選**：支援即時輸入座號、姓名或學號快搜，並提供「全部 (31人) / ⚠️ 僅未繳費 / ✅ 僅已繳費」標籤，催繳對帳秒查。
- **⚡ 座號快速跳轉膠囊列**：可橫向滑動點擊 1~31 號，平滑跳轉至該學生卡片並高亮提示。
- **📌 手機底部常駐懸浮資訊條**：滑動長名單時隨時掌握「全班應收總額」與「實收進度」，並可一鍵回頂端或秒切換表格。
- **七大品項即時算費**：
  1. 夏季短袖制服上衣 ($55)
  2. 冬季長袖制服上衣 ($55)
  3. 夏季短袖運動上衣 ($55)
  4. 冬季長袖運動上衣 ($55)
  5. 各科實習服 ($55)
  6. 帽子 ($55)
  7. 冬季棒球運動外套 ($65)
- **智慧連動**：每位學生之個人合計金額與全班各品項總件數、應收總金額、已繳費進度即時連動計算。
- **快捷工具**：支援「一鍵套用標準全套 7 件 ($395)」、「填入 31 位示範名冊」、「一鍵清空」。
- **A4 完美列印**：完全遵照官方 PDF 03 格式排版，包含班長簽章、總務股長簽章、導師簽章與班級資訊，點擊「列印收費表」即可直接輸出紙本或存為 PDF。
- **資料自動保存**：輸入之姓名、學號與件數均自動儲存於本機瀏覽器，重新整理或關閉視窗不遺失。
- **支援 CSV 匯出與匯入**：可將 31 人名冊匯出為 Excel 相容的 CSV 檔案，亦可將已打好名單的 CSV 匯入。

### 2. 🗓️ 01 繡學號日程表
- **完整呈現關鍵日程**：
  - **9/22 (二)**：便服收繳時間。
  - **9/23 (三)**：補行送繡最後一日。
  - **9/24 (四)**：廠商預計送回學校／新生體檢日。
  - **12/1 (二)**：建教班一信乙特別協調。
- **便服規定防呆提醒**：註明便服日不得穿著裙子、短褲、薄紗、破衣褲，以及體檢日便服輕便穿脫原則。
- **教官室諮詢窗口**：生輔組長 蘇教官 (02-29411831 或 02-29432491 轉 510)。

### 3. 📌 02 送繡標準作業流程 (SOP)
- **圖解 5 大步驟**：領取物料 → 貼 A 貼紙核對學號 → 裝 B 袋貼 C 貼紙 → 總務股長對點收費 → 裝 D 班級麻布袋校門對點交件。
- **四大物料說明**：A (12小張)、B (個人袋)、C (袋標)、D (班級麻布袋)。

### 4. 💵 總務現金對帳計算機
- 總務股長收齊現金後，輸入 1000、500、100、50、10、5、1 元之張數或枚數，系統立即核對實收與應收總額是否相符。
